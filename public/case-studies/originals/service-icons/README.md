# Service icons

Local service icons reused from the [Diagrams resource library](https://github.com/mingrammer/diagrams/tree/master/resources). Diagrams is [MIT licensed](https://github.com/mingrammer/diagrams/blob/master/LICENSE). AWS, Cloudflare and PostgreSQL marks identify the services shown; they imply no endorsement or certification.

These are authoring assets embedded in the original architecture SVGs. The deployed portfolio uses self-hosted WebP images; no remote icon or font request is required.

The diagrams are reading views of the linked project documentation, not generated inventories. TerraGate follows its October 10 Cloudflare/AWS/Neon release record. ShiftClarity follows its October 13 deployed synthetic-pilot C4 record. Production and reference boundaries remain explicit in the page and image.
